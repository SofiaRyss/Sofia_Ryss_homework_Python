# Домашнее задание №10: Документирование и Allure

## 📋 Описание проекта
В данной папке представлено решение домашнего задания №10. 

Проект включает в себя:
- **Page Object Model** для двух веб-приложений:
  - Медленный калькулятор (https://bonigarcia.dev/selenium-webdriver-java/slow-calculator.html)
  - Интернет-магазин SauceDemo (https://www.saucedemo.com/)
- **Полное документирование кода** (docstrings с указанием типов параметров и возвращаемых значений)
- **Интеграцию с Allure** для формирования красивых отчётов о тестировании
